# Tweaks Anthology Custom Lite

A strictly personal custom build of **The Tweaks Anthology v18**.

This variant removes components that can cause or contribute to **slowdown, lag, stutter, or partial/overall performance degradation** in a heavily modded setup, while keeping selected exceptions by personal preference.

## Retained exceptions

The following components are intentionally kept available:

- **#3040** — Make Bags of Holding Bottomless
- **#3280** — Give Every Class/Kit Four Weapon Slots
- **#3410** — Explicit Cast Warnings (Mage and Priest spells)
- **#3411** — Explicit Cast Warnings (Mage, Priest and Innate)
- **#3412** — Explicit Cast Warnings (All Spells)
- **#4160** — Allow Yeslick to Use Axes
